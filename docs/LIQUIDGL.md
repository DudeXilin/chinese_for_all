# liquidGL в этом проекте — как с ним работать

Это инструкция для следующего ИИ/разработчика, который будет добавлять
или менять что-то, связанное с эффектом "жидкого стекла". Читай перед
тем, как трогать что-либо из списка ниже.

## Откуда это

Библиотека **не наша**, это открытый проект NaughtyDuk:

- Репозиторий: https://github.com/naughtyduk/liquidGL
- Демки: https://liquidgl.naughtyduk.com/demos/demo-1 (и demo-2..demo-5)
- Лицензия: MIT

Файлы лежат в `public/scripts/`:

- `liquidGL.js` — сама библиотека. **Никогда не редактировать вручную.**
  Если нужно обновиться до новой версии автора — просто скачать файл
  заново с GitHub (`scripts/liquidGL.js` в его репозитории) и
  заменить целиком.
- `liquidGL-helper.js` — официальная панель отладки автора (лежит
  там же в его репозитории).

Если через некоторое время автор снова что-то обновит — стоит свериться
с его README и changelog (there's a version comment in the header of
`liquidGL.js`), и при необходимости обновить оба файла тем же способом.

## Как это работает (коротко)

1. Один общий `<canvas>` на всю страницу — рисует WebGL-преломление
   фона под каждым "стеклянным" элементом.
2. `liquidGL({ target: ".some-class", ... })` находит все элементы с
   этим классом на странице и делает каждый из них "линзой": элемент
   становится (после короткой паузы на захват снимка фона) прозрачным
   изнутри, но остаётся в DOM как обычно.
3. `snapshot: "body"` — что именно фотографируется как фон для
   преломления (в нашем случае всегда весь `<body>`).

## Правило №1: контент — ВНУТРИ target, а не рядом

Наступил на эти грабли один раз — больше не наступать.

Правильно (как в demo-1 у автора):

```html
<a href="/lessons">
  <div class="cfa-glass">
    <span>Начать обучение</span>
  </div>
</a>
```

`div.cfa-glass` — это и есть target. Текст/иконка внутри него —
**обычный дочерний элемент**, не отдельный слой рядом. Это работает,
потому что `opacity: 0` и `background: transparent`, которые liquidGL
временно ставит на target во время захвата снимка, потом снимаются
(смотри `originalOpacity` в коде библиотеки) — контент внутри снова
становится видимым.

`pointer-events: none`, который liquidGL ставит на target насовсем —
не проблема: кликабельным должен быть **родитель** (`<a>` или
`<button>`), а не сам target. Клик проходит "сквозь" target к
родителю.

Неправильно (так делать не надо — именно так текст пропадал):

```html
<!-- НЕ ТАК -->
<a href="...">
  <div class="cfa-glass"></div>          <!-- отдельно -->
  <span>Текст</span>                      <!-- отдельно -->
</a>
```

## Правило №2: все target-элементы на одной странице должны иметь ОДИНАКОВЫЙ z-index

У эффекта один общий `<canvas>` на страницу, и его z-index
вычисляется как `(максимальный z-index среди всех target-ов) - 1`.

Если у одной кнопки z-index условно 100000, а у другой 9999 — canvas
окажется ВЫШЕ второй кнопки, и её содержимое визуально пропадёт под
canvas-ом. Именно так один раз сломался текст на кнопке "Начать
обучение".

**Правило: у всех fixed/absolute-обёрток с liquidGL-элементами на
одной странице должен быть один и тот же z-index.** В этом проекте
используется `z-index: 9999` для всех обёрток на `index.html`
(профиль-кнопка, кнопка "Начать обучение"), и отдельные небольшие
значения (например 120) на страницах, где liquidGL-элемент только
один (там неважно, что именно за число, лишь бы не 0/auto).

z-index достаточно поставить один раз на элемент, который: (а)
`position` не `static`, и (б) является ближайшим таким предком
target-а. Дочерним элементам ставить z-index не нужно — библиотека
сама поднимается по дереву предков и берёт первый найденный.

## Два разных места использования в проекте

1. **`public/index.html` (статичная главная страница).** Не React.
   Все скрипты подключены обычными `<script>` тегами в конце файла.
   Здесь используется класс **`.liquidGL`** (совпадает с дефолтным
   именем библиотеки) — сейчас это единственная кнопка "Начать
   обучение" (`public/js/main.js`). Профиль-кнопка на этой же
   странице использует класс `.cfa-glass` — отдельный вызов
   `liquidGL()` в `public/js/auth.js`, с настройками, подходящими для
   маленькой круглой кнопки.

2. **React-страницы (`/profile`, `/lessons`, `/lessons/[slug]` и
   т.д.).** Здесь есть компонент `components/glass-init.tsx`:

   ```tsx
   <script src="/scripts/liquidGL.js" />
   <GlassInit target=".cfa-glass" />
   ```

   `GlassInit` — это маленький клиентский компонент, который на
   монтировании вызывает `window.liquidGL(...)` с настройками из
   `DEFAULT_GLASS_OPTIONS` (экспортированы из этого же файла — это
   единый источник правды для дефолтных настроек эффекта). Если нужно
   переопределить что-то для конкретного места — передать `options`:

   ```tsx
   <GlassInit target=".cfa-glass" options={{ magnify: 1.5 }} />
   ```

   Новую "стеклянную" кнопку/карточку на React-странице делать так:
   1. Добавить `<script src="/scripts/liquidGL.js" />` на страницу
      (если его там ещё нет).
   2. Добавить `<GlassInit target=".cfa-glass" />` (один раз на
      страницу, даже если target-элементов несколько — один вызов
      подхватит их все).
   3. Разметку строить по Правилу №1 (контент внутри target) и
      Правилу №2 (одинаковый z-index у всех обёрток на этой
      странице).

## Дефолтные настройки (актуальные на сейчас)

Единый источник — `DEFAULT_GLASS_OPTIONS` в `components/glass-init.tsx`:

```js
{
  snapshot: "body",
  resolution: 1.5,
  refraction: 0.002,
  aberration: 0.1,
  bevelDepth: 0.04,
  bevelWidth: 0.264,
  frost: 0,
  shadow: true,
  specular: true,
  reveal: "fade",
  tilt: false,
  tiltFactor: 10,
  tiltEase: 400,
  magnify: 1.2,
  helper: false,
}
```

Кнопка "Начать обучение" на главной странице (`public/js/main.js`)
использует немного другие числа (по историческим причинам — так было
настроено ещё для старого большого окна в центре экрана, стиль решили
оставить). Если понадобится — можно привести к единому виду с
`DEFAULT_GLASS_OPTIONS`, но пока осознанно оставлено как есть.

## Панель отладки (helper)

`helper: true` в вызове `liquidGL()` включает официальную панель
автора (нужно, чтобы `liquidGL-helper.js` тоже был подключён
`<script>`-тегом). Сейчас включена на главной странице
(`public/js/main.js`), сдвинута в левый верхний угол через override в
`public/css/components.css` (у автора она жёстко прибита `!important`
в правый верхний угол, так что override сделан с более высокой
специфичностью, а не просто более поздним правилом).

## Частые ошибки, которые уже случались

- **Текст/иконка пропадает** → почти всегда Правило №2 (разный
  z-index у обёрток на одной странице).
- **Дёргается на iOS при скролле** → в версии library ≥ на момент
  этой заметки (после обновления с v2.0.1 до v2.2.4) уже исправлено
  апстримом (пересчёт откладывается до конца скролла). Если проблема
  вернётся — сначала проверить, не устарела ли `liquidGL.js`.
- **Эффект видно, но кнопка не кликается** → клик должен ловить
  родитель target-а (`<a>`/`<button>`), не сам target.
- **Стекло "мерцает"/остаётся видимым, когда должно быть скрыто**
  (например, для выпадающего меню, которое то показывается, то
  прячется через `opacity`/`display`) → liquidGL не проверяет
  видимость предков перед отрисовкой линзы на canvas. Для элементов,
  которые именно **переключаются** (не постоянно на экране), проще и
  надёжнее использовать обычное CSS-стекло (`backdrop-filter: blur()`)
  вместо настоящего liquidGL — так сделано для выпадающего меню
  "Войти/Регистрация" на главной странице.
