# SUBTLEX-CH — частотности китайских слов и иероглифов

## Статус данных в этой папке

Этот каталог предназначен для файлов оригинального набора **SUBTLEX-CH** Qing Cai и Marc Brysbaert (2010). Набор рассчитан по китайским субтитрам фильмов и телепередач на упрощённом китайском.

**Оригинальные источники:**
- Статья и описание методики: https://doi.org/10.1371/journal.pone.0010729
- Архив с тремя таблицами (Files S1, ZIP): https://doi.org/10.1371/journal.pone.0010729.s002
- Таблица меток частей речи PKU (Table S1, DOC): https://doi.org/10.1371/journal.pone.0010729.s001

> Важно: README не является заменой оригинальным файлам. Перед добавлением или распространением самих таблиц проверьте условия их использования у авторов. В статье указано, что частотности предоставляются бесплатно для исследовательских целей; это не следует автоматически трактовать как разрешение на любое коммерческое или иное распространение.

## Что входит в набор

В оригинальном ZIP авторы указывают три файла:

| Файл | Содержание |
|---|---|
| `SUBTLEX-CH-WF` | Частотность слов целиком |
| `SUBTLEX-CH-CHR` | Частотность отдельных иероглифов независимо от того, входят ли они в многосимвольные слова |
| `SUBTLEX-CH-WF_PoS` | Частотность слов с разбивкой по частям речи (PoS) |

Корпус, на котором рассчитаны показатели, содержит примерно 33,5 млн слов и 46,8 млн иероглифов/символов из 6 243 контекстов (фильмов или эпизодов). В таблице слов около 99 121 различных словоформ, в таблице иероглифов — 5 936 символов.

## Поля частотности слов: `SUBTLEX-CH-WF`

| Поле | Значение | Как использовать |
|---|---|---|
| `Word` | Слово на китайском | Ключ для поиска. Сверяйте точное написание; таблица построена на упрощённом китайском. |
| `WCount` | Сколько раз слово встретилось во всём корпусе | Абсолютная частота. Большое значение означает больше появлений в собранных субтитрах. |
| `W/million` | Число появлений на миллион слов корпуса | Нормализованная частота, удобная для сравнения значений между корпусами разного размера. |
| `logW` | Десятичный логарифм `WCount`, то есть `log10(WCount)` | Сжимает большой диапазон частот. Полезен для сортировки и статистических моделей; это не «оценка сложности». |
| `W-CD` | Contextual diversity: число разных фильмов/эпизодов, где встретилось слово | Показывает, насколько широко слово распределено по контекстам, а не только сколько раз повторилось в одном контексте. |
| `W-CD%` | Процент контекстов, где слово встретилось | Нормализованная contextual diversity. В статье максимум — 6 243 контекста; показатель приблизительно соответствует `100 × W-CD / 6243`. |
| `logW-CD` | Десятичный логарифм `W-CD`, то есть `log10(W-CD)` | Логарифмический показатель разнообразия контекстов. |

В некоторых копиях заголовок первого столбца может отличаться по написанию. При импорте ориентируйтесь на заголовки исходного файла и не переименовывайте столбцы без необходимости.

## Поля частотности иероглифов: `SUBTLEX-CH-CHR`

| Поле | Значение | Как использовать |
|---|---|---|
| `Character` | Отдельный китайский иероглиф | Ключ для поиска. |
| `CHRCount` | Общее количество появлений иероглифа в корпусе из примерно 46,8 млн символов | Абсолютная частота символа. Считается и в составе многосимвольных слов. |
| `CHR/million` | Число появлений на миллион символов корпуса | Нормализованная частота, удобная для сравнения. |
| `logCHR` | `log10(CHRCount)` | Логарифм абсолютной частоты. |
| `CHR-CD` | Число разных фильмов/эпизодов, где встречался иероглиф | Контекстное разнообразие символа. |
| `CHR-CD%` | Процент контекстов, где встречался иероглиф | Нормализованное контекстное разнообразие. |
| `logCHR-CD` | `log10(CHR-CD)` | Логарифм контекстного разнообразия. |

Частота иероглифа не равна частоте слова, в котором он используется. Например, частота 字 в таблице символов учитывает появления этого символа во всех словах, а не только самостоятельное употребление.

## Файл `SUBTLEX-CH-WF_PoS`: частотность по частям речи

Этот файл нужен, когда одно и то же написание может выступать разными частями речи — например, существительным, глаголом или прилагательным.

Структура описана авторами так:
- Строка, начинающаяся со слова, обозначает лемму и её общую частоту `WF` (по смыслу сопоставима с `WCount` в таблице слов).
- Строки, начинающиеся с `@→@`, перечисляют возможные части речи для этой леммы.
- Метка части речи соответствует системе тегов **PKU**.
- Значения `WF_PoS` показывают, сколько раз лемма встретилась в конкретной синтаксической роли; суммы частот по ролям должны соответствовать общей частоте `WF` этой леммы.

Список и расшифровки тегов PKU находятся в официальной таблице S1: https://doi.org/10.1371/journal.pone.0010729.s001. Используйте именно этот список, а не сопоставляйте теги с другими системами PoS по похожим буквам.

В этой таблице авторы **не рассчитывали contextual diversity отдельно для частей речи**. Поэтому не следует ожидать для каждой роли аналогов `W-CD` или `W-CD%`.

## Как выбирать показатель

- Для сортировки слов по частотности в обычном интерфейсе обучения используйте `W/million` или `WCount`.
- Для сравнения слов на разных масштабах корпуса предпочтительнее нормализованные показатели `W/million` и `CHR/million`.
- Если важно, насколько широко слово встречается в разных сюжетах, используйте `W-CD` или `W-CD%`, а не только общее число повторений.
- Для частотности отдельного иероглифа используйте таблицу `CHR`; не выводите её из частоты слов.
- Если нужно различать грамматические функции одного написания, используйте `WF_PoS`.
- Не трактуйте частотность как прямую оценку уровня HSK, сложности, полезности для конкретного ученика или вероятности встретить слово в любой современной ситуации. Это оценка по корпусу субтитров, собранному для исследования 2010 года.

## Формулы

Для слов:
- `W/million = WCount / общее число слов корпуса × 1 000 000`
- `logW = log10(WCount)`
- `W-CD% ≈ W-CD / 6243 × 100`
- `logW-CD = log10(W-CD)`

Для иероглифов:
- `CHR/million = CHRCount / общее число символов корпуса × 1 000 000`
- `logCHR = log10(CHRCount)`
- `CHR-CD% ≈ CHR-CD / 6243 × 100`
- `logCHR-CD = log10(CHR-CD)`

Используйте значения, рассчитанные авторами, как исходные. Формулы приведены для понимания показателей и проверки данных; из-за округления нормализованные значения могут немного отличаться от результата самостоятельного пересчёта.

## Пример использования

Чтобы найти частотность слова `苹果` («яблоко»):
1. Найдите точное слово `苹果` в `SUBTLEX-CH-WF`.
2. Смотрите `W/million` для нормализованной частоты.
3. Смотрите `W-CD%` или `W-CD`, чтобы понять, во скольких разных контекстах оно появлялось.
4. При необходимости откройте `SUBTLEX-CH-WF_PoS`, чтобы изучить грамматические роли слова.

Чтобы оценить отдельный иероглиф `苹`, найдите его в `SUBTLEX-CH-CHR`. Это значение относится ко всем его появлениям в корпусе, а не только к слову `苹果`.

## Импорт в код

Оригинальные таблицы следует сначала изучить на предмет формата (разделитель, кодировка, заголовки), а затем читать с явным указанием этих параметров. Не предполагайте, что файл — CSV с запятыми: табличные выгрузки могут использовать табуляцию или иной разделитель.

Рекомендации для приложения:
1. Хранить оригинальные файлы без ручного редактирования.
2. При необходимости конвертировать данные в JSON/SQLite отдельным скриптом, сохраняя исходники и документируя конвертацию.
3. Нормализовать ключи осторожно: не менять иероглифы, не удалять символы из слов и не смешивать упрощённое и традиционное написание автоматически.
4. Обрабатывать отсутствующее слово как «нет записи в этом корпусе», а не как доказательство того, что слово не существует.
5. Указывать источник данных и публикацию при использовании частотностей.
