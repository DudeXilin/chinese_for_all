# SUBTLEX-CH — частотность китайских слов и иероглифов

SUBTLEX-CH — частотные списки китайского языка, построенные на корпусе субтитров фильмов и телесериалов. В исходной публикации описаны **33 546 516 слов**, **46 841 097 иероглифов** и **6 243 контекста** (фильма/видео).

## Источник и цитирование

- Cai, Q. & Brysbaert, M. (2010). *SUBTLEX-CH: Chinese Word and Character Frequencies Based on Film Subtitles*. PLOS ONE 5(6): e10729. https://doi.org/10.1371/journal.pone.0010729
- Официальный архив исходных таблиц: https://doi.org/10.1371/journal.pone.0010729.s002
- Дополнительная таблица с кодами частей речи PKU: https://doi.org/10.1371/journal.pone.0010729.s001
- Страница проекта авторов: https://www.ugent.be/pp/experimentele-psychologie/en/research/documents/subtlexch

При использовании данных цитируйте указанную публикацию. Страница проекта авторов указывает бесплатную загрузку для некоммерческого использования; перед распространением исходных данных в публичном репозитории проверьте действующие условия использования и атрибуции. В этом репозитории нет исходных субтитров — только частотные таблицы.

## Состав папки

| Файл | Содержание |
|---|---|
| `SUBTLEX-CH-CHR.json` | Таблица частотности иероглифов, JSON |
| `SUBTLEX-CH-WF.part-01.json` … `SUBTLEX-CH-WF.part-17.json` | Полная таблица частотности слов, разбитая на 17 JSON-частей из-за размера файла |
| `README.md` | Эта документация |

Каждая часть WF содержит одинаковые `metadata` и `headers`, поля `chunkIndex` / `chunkCount`, исходную позицию `rowStart` и массив `data` со строками таблицы. Чтобы восстановить единую таблицу, объедините массивы `data` в порядке частей 01–17. Файлы JSON подготовлены из опубликованного зеркала структурированных данных; значения таблиц и исходные заголовки сохранены, но представление JSON и разбиение на части — это формат хранения в этом репозитории, а не исходный формат авторского ZIP.

**Важное ограничение:** исходный официальный архив содержит три таблицы: `SUBTLEX-CH-WF`, `SUBTLEX-CH-CHR` и `SUBTLEX-CH-WF_PoS`. В эту папку добавлены полные таблицы WF и CHR. Файл `SUBTLEX-CH-WF_PoS` пока не добавлен: доступные зеркала предоставляют WF и CHR, но не сам исходный PoS-файл. Его нельзя достоверно восстановить из WF, потому что он содержит отдельные частоты для разных частей речи. Оригинал можно получить из официального архива по ссылке выше. Не считайте третью таблицу установленной до её отдельного добавления.

## Формат и загрузка

Файлы JSON закодированы в UTF-8. Китайские символы сохраняются напрямую. Поля таблиц доступны по названиям в `headers`, а каждая запись — это объект внутри `data`. Обратите внимание: в зеркале, из которого подготовлены WF-части, поле метаданных называется `metadata.totalCharacterCount`, хотя значение 33 546 516 обозначает число слов корпуса для WF. Не используйте это имя метаданных как источник знаменателя для расчёта `W/million`; используйте документацию и исходный показатель.

### Загрузить таблицу иероглифов

```ts
import { readFileSync } from "node:fs";

const characters = JSON.parse(
  readFileSync("lib/SUBTLEX-CH/SUBTLEX-CH-CHR.json", "utf8"),
);

const row = characters.data.find((item) => item.Character === "人");
console.log(row?.["CHR/million"], row?.["CHR-CD%"]);
```

### Загрузить и объединить таблицу слов

```ts
import { readFileSync } from "node:fs";
import { join } from "node:path";

const dir = "lib/SUBTLEX-CH";
const chunks = Array.from({ length: 17 }, (_, index) => {
  const part = String(index + 1).padStart(2, "0");
  return JSON.parse(
    readFileSync(join(dir, `SUBTLEX-CH-WF.part-${part}.json`), "utf8"),
  );
});

const words = chunks.flatMap((chunk) => chunk.data);
const apple = words.find((row) => row.Word === "苹果");
console.log(apple?.["W/million"], apple?.["W-CD%"]);
```

Эти примеры рассчитаны на серверный Node.js/скрипты. Не импортируйте все данные непосредственно в клиентский JavaScript без оценки размера bundle и памяти. Для интерфейса лучше подготовить компактный индекс или выполнять поиск на сервере.

## Поля SUBTLEX-CH-WF — слова

Исходные заголовки: `Word`, `WCount`, `W/million`, `logW`, `W-CD`, `W-CD%`, `logW-CD`.

| Поле | Что означает | Как читать |
|---|---|---|
| `Word` | Китайская словарная единица/строка | Ключ для поиска записи. |
| `WCount` | Абсолютное число употреблений слова во всём корпусе | Сколько раз слово встретилось среди примерно 33,5 млн слов. |
| `W/million` | Частота на миллион слов | Нормализованный показатель. Например, значение 100 означает 100 зарегистрированных употреблений на миллион слов корпуса. |
| `logW` | Десятичный логарифм абсолютной частоты `WCount` | Логарифмически сжатый показатель, удобный для сравнения очень частотных и редких слов. Это не процент. |
| `W-CD` | Contextual diversity: число контекстов, где встретилось слово | Сколько из 6 243 фильмов/видео содержали слово хотя бы один раз. |
| `W-CD%` | Процент контекстов, где встретилось слово | `W-CD / 6243 × 100`. Например, 7.14 означает около 7.14% контекстов. |
| `logW-CD` | Десятичный логарифм `W-CD` | Логарифмическое представление числа контекстов. |

**Для рейтинга слов:** используйте `W/million` как основную меру частоты, а `W-CD%` — как дополнительную меру того, насколько широко слово распределено по разным фильмам. Слово может много раз повторяться в одном фильме и иметь высокий `WCount`, но сравнительно низкий `W-CD%`.

## Поля SUBTLEX-CH-CHR — иероглифы

Исходные заголовки: `Character`, `CHRCount`, `CHR/million`, `logCHR`, `CHR-CD`, `CHR-CD%`, `logCHR-CD`.

| Поле | Что означает | Как читать |
|---|---|---|
| `Character` | Один иероглиф/символ | Ключ для поиска. |
| `CHRCount` | Абсолютное число появлений символа | Считает символ везде, в том числе внутри слов; не означает, что символ использовался отдельно как слово. |
| `CHR/million` | Число появлений на миллион иероглифов | Нормализованная частота символа; знаменатель — символы, не слова. |
| `logCHR` | Десятичный логарифм `CHRCount` | Логарифмическая мера абсолютной частоты. |
| `CHR-CD` | Число контекстов, где встретился символ | Сколько из 6 243 фильмов/видео содержали иероглиф. |
| `CHR-CD%` | Процент контекстов, где встретился символ | `CHR-CD / 6243 × 100`. |
| `logCHR-CD` | Десятичный логарифм `CHR-CD` | Логарифмическая мера распространённости по контекстам. |

**Не сравнивайте напрямую `W/million` и `CHR/million`:** первая величина рассчитана на миллион слов, вторая — на миллион иероглифов. Это разные знаменатели и разные единицы измерения.

## Поля в расширенном объединённом PoS-файле

На странице проекта авторов также описан расширенный объединённый файл, содержащий частоты слов и грамматических ролей, пиньинь и справочные переводы. В нём могут встречаться следующие поля:

| Поле | Значение |
|---|---|
| `Length` | Количество символов в слове |
| `W.million` | Частота слова на миллион слов |
| `Dominant.PoS` | Часть речи с наибольшей частотой |
| `Dominant.PoS.Freq` | Частота доминирующей части речи |
| `All.PoS` | Все грамматические роли, в которых встречалось слово |
| `All.PoS.Freq` | Частоты соответствующих грамматических ролей |
| `Pinyin` | Пиньинь с номерами тонов в описанной производной версии |
| `Pinyin.Input` | Справочный вариант пиньиня для ввода без тонов |
| `WCount` | Абсолютное число употреблений слова |
| `log10W` | Десятичный логарифм `WCount` |
| `W-CD` | Число контекстов с этим словом |
| `W-CD%` | Процент контекстов с этим словом |
| `log10CD` | Десятичный логарифм `W-CD` |
| `Eng.Tran` | Справочный английский перевод из CEDICT в этой производной версии |

Это описание именно расширенной объединённой версии; заголовки и порядок полей в исходном `SUBTLEX-CH-WF_PoS` могут отличаться. Не предполагайте, что все перечисленные столбцы присутствуют в любом файле с похожим названием.

### Примеры кодов частей речи PKU

Коды происходят из системы разметки Пекинского университета (PKU):

- `n` — существительное; `v` — глагол; `a` — прилагательное.
- `d` — наречие; `r` — местоимение; `m` — числительное.
- `p` — предлог; `c` — союз; `q` — классификатор.
- `nr` — имя человека; `ns` — географическое название; `nt` — название организации.
- `i` — идиома; `u` — служебная единица/частица; `w` — знак или пунктуация.

Это лишь примеры. Полный список кодов и определений приведён в официальной дополнительной таблице S1.

## Пример расчёта

В данных слово `苹果` имеет `WCount = 766`, `W/million = 22.83`, `W-CD = 446`, `W-CD% = 7.14`. Это значит, что слово встретилось 766 раз в корпусе, примерно 22.83 раза на миллион слов, и было обнаружено в 446 из 6 243 контекстов (около 7.14%).

Для иероглифа `人` `CHR/million` показывает частоту символа на миллион иероглифов. Это не частота слова «человек» — для слова нужно смотреть отдельную запись в WF.

## Методологические ограничения

- Корпус отражает субтитры отобранных фильмов и видео, а не все современные разговоры или весь интернет.
- Частота в субтитрах не равна точной вероятности услышать слово в любом конкретном видео.
- `W-CD%` измеряет распространённость по документам корпуса, а не процент всех видео на китайском языке.
- Сегментация китайского текста на слова влияет на то, какие единицы учитываются в WF.
- Данные отражают корпус исследования 2010 года и не должны считаться актуальным рейтингом трендовых слов.
