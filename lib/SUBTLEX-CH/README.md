# SUBTLEX-CH

Данные SUBTLEX-CH — частотные списки китайских слов и иероглифов, построенные по субтитрам фильмов и телесериалов. Исходное исследование сообщает корпус объёмом 33,5 млн слов и 46,8 млн иероглифов, собранных из 6 243 контекстов (фильмов/видео).

## Источник и цитирование

- Cai, Q. & Brysbaert, M. (2010). *SUBTLEX-CH: Chinese Word and Character Frequencies Based on Film Subtitles*. PLOS ONE 5(6): e10729. https://doi.org/10.1371/journal.pone.0010729
- Официальные дополнительные данные: https://doi.org/10.1371/journal.pone.0010729.s002
- Дополнительная таблица с кодами частей речи PKU: https://doi.org/10.1371/journal.pone.0010729.s001
- Страница проекта авторов: https://www.ugent.be/pp/experimentele-psychologie/en/research/documents/subtlexch

При использовании данных следует цитировать указанную публикацию. Оригинальные материалы были предоставлены авторами для исследовательских целей; перед дальнейшим распространением оригинальных файлов проверьте применимые условия использования и атрибуции. Этот репозиторий не содержит исходные субтитры — только частотные таблицы.

## Состав папки

| Файл | Содержание |
|---|---|
| `SUBTLEX-CH-WF.tsv` | Частотность слов (Word Frequency) |
| `SUBTLEX-CH-CHR.tsv` | Частотность отдельных иероглифов (Character Frequency) |
| `README.md` | Документация и описание показателей |

**Важно:** исходный архив PLOS ONE содержит три таблицы: `SUBTLEX-CH-WF`, `SUBTLEX-CH-CHR` и `SUBTLEX-CH-WF_PoS`. В текущей копии доступны полные таблицы WF и CHR. Таблица `WF_PoS` не включена в эти два зеркала данных; её нельзя корректно восстановить из WF, поскольку она содержит отдельные частоты слов по грамматическим ролям. Оригинал можно получить из официального архива по ссылке выше. Не считайте `WF_PoS` установленной в этой папке, пока файл не добавлен отдельно.

## Формат таблиц

Таблицы сохранены как TSV (значения разделены табуляцией), кодировка UTF-8. Первая строка — заголовки столбцов. При чтении программой укажите разделитель `\t`, а не запятую. Китайские символы должны читаться как UTF-8.

## Поля в SUBTLEX-CH-WF.tsv (слова)

| Поле | Значение | Как читать |
|---|---|---|
| `Word` | Слово в китайском написании | Ключ для поиска слова. |
| `WCount` | Абсолютное число употреблений слова во всём корпусе | Чем больше число, тем чаще слово встретилось в собранных субтитрах. |
| `W/million` | Частота на миллион слов корпуса | Удобный нормализованный показатель для сравнения слов и корпусов разного размера. Например, 100 означает около 100 употреблений на каждый миллион слов корпуса. |
| `logW` | Десятичный логарифм `WCount` | Сжимает широкий диапазон частот. В оригинальных/производных версиях поле может называться `log10W`. |
| `W-CD` | Contextual diversity: число фильмов/контекстов, в которых слово встретилось | Высокое значение означает, что слово встречается в большем числе разных контекстов, а не только многократно в одном фильме. Всего в исходном наборе 6 243 контекста. |
| `W-CD%` | Доля контекстов, в которых встретилось слово, в процентах | Рассчитывается как `W-CD / 6243 × 100` для исходного корпуса. Это не вероятность появления слова в произвольном видео другого жанра. |
| `logW-CD` | Десятичный логарифм числа контекстов `W-CD` | Логарифмический вариант меры распространённости по контекстам. В объединённом файле может называться `log10CD`. |

### Как выбирать показатель слова

- Для простого ранжирования по частоте используйте `W/million` или `WCount`.
- Для оценки того, насколько широко слово распространено между разными фильмами, используйте `W-CD%` или `W-CD`.
- Для сравнения рейтингов обычно удобнее `W/million`, поскольку абсолютные счётчики зависят от размера корпуса.
- `WCount` и `W-CD` отвечают на разные вопросы: первое считает все появления, второе — в скольких разных контекстах слово встретилось.

## Поля в SUBTLEX-CH-CHR.tsv (иероглифы)

| Поле | Значение | Как читать |
|---|---|---|
| `Character` | Один китайский иероглиф | Ключ для поиска символа. |
| `CHRCount` | Абсолютное число появлений иероглифа в корпусе | Количество всех вхождений символа, независимо от того, в составе какого слова он встретился. |
| `CHR/million` | Число появлений на миллион иероглифов корпуса | Нормализованная частота символа. Знаменатель — символы, а не слова. |
| `logCHR` | Десятичный логарифм `CHRCount` | Логарифмическая мера частоты; не линейный процент. |
| `CHR-CD` | Число фильмов/контекстов, где встретился иероглиф | Мера распространённости по контекстам. |
| `CHR-CD%` | Доля фильмов/контекстов, где встретился иероглиф, в процентах | Для исходного корпуса знаменатель — 6 243 контекста. |
| `logCHR-CD` | Десятичный логарифм `CHR-CD` | Логарифмическая мера распространённости по контекстам. |

### Важное различие

Частота слова считается на миллион **слов**, а частота иероглифа — на миллион **иероглифов**. Поэтому значения `W/million` и `CHR/million` нельзя напрямую сравнивать друг с другом. Иероглиф также может встречаться в составе множества слов; его частота не является частотой отдельного слова.

## Таблица SUBTLEX-CH-WF_PoS (части речи)

Исходный третий файл содержит частоты слова с учётом разных синтаксических ролей (PoS, part of speech). Он нужен, когда одна и та же форма употребляется, например, как существительное и как глагол. Для него существуют отдельные частоты по грамматическим ролям; они не эквивалентны общей частоте слова.

В расширенном объединённом варианте файла могут встречаться следующие поля:

| Поле | Значение |
|---|---|
| `Word` | Слово |
| `Length` | Число иероглифов в слове |
| `W.million` | Частота слова на миллион слов |
| `Dominant.PoS` | Часть речи с наибольшей частотой |
| `Dominant.PoS.Freq` | Частота доминирующей части речи |
| `All.PoS` | Все грамматические роли слова |
| `All.PoS.Freq` | Частоты соответствующих грамматических ролей |
| `Pinyin` | Пиньинь с номерами тонов в этой производной версии |
| `Pinyin.Input` | Вариант пиньиня для ввода без обозначения тона; справочное поле |
| `WCount` | Абсолютное количество употреблений слова |
| `log10W` | Десятичный логарифм `WCount` |
| `W-CD` | Число контекстов, в которых встретилось слово |
| `W-CD%` | Процент контекстов, в которых встретилось слово |
| `log10CD` | Десятичный логарифм `W-CD` |
| `Eng.Tran` | Справочный английский перевод, полученный из словаря CEDICT в производном файле |

Это описание относится к расширенной объединённой версии, опубликованной на странице проекта авторов; состав и порядок столбцов исходного `WF_PoS` могут отличаться. Не предполагайте, что все перечисленные поля присутствуют в каждом файле с таким названием.

### Коды PKU PoS

В файле частей речи используются коды теггера Пекинского университета (PKU), например:

- `n` — существительное; `v` — глагол; `a` — прилагательное.
- `d` — наречие; `r` — местоимение; `m` — числительное.
- `p` — предлог; `c` — союз; `u` — служебная частица/вспомогательная единица.
- `nr` — имя человека; `ns` — географическое название; `nt` — название организации.
- `q` — классификатор; `i` — идиома; `w` — знак или пунктуация.

Это лишь примеры, не полный перечень. Полный список кодов и определений находится в официальной дополнительной таблице S1.

## Пример чтения записи

Если у слова `WCount = 3350`, а корпус содержит 33 500 000 слов, его частота равна:

`3350 / 33,500,000 × 1,000,000 = 100`

То есть `W/million = 100`: в корпусе зафиксировано 100 употреблений на миллион слов. Это средняя частота по корпусу, а не гарантия равномерного распределения по тексту.

## Пример чтения на JavaScript / TypeScript

```ts
import { readFileSync } from "node:fs";

const text = readFileSync(
  "lib/SUBTLEX-CH/SUBTLEX-CH-WF.tsv",
  "utf8",
);

const [headerLine, ...lines] = text.trimEnd().split(/\r?\n/);
const headers = headerLine.split("\t");

const rows = lines.map((line) => {
  const values = line.split("\t");
  return Object.fromEntries(headers.map((header, i) => [header, values[i]]));
});

const apple = rows.find((row) => row.Word === "苹果");
console.log(apple?.["W/million"], apple?.["W-CD%"]);
```

Числовые значения в приведённом примере читаются как строки; при расчётах преобразуйте их через `Number(...)`. Для браузерного кода не импортируйте полный файл напрямую без оценки размера bundle: предпочтительно читать данные на сервере или подготовить отдельный компактный индекс.

## Источники полей и методология

Показатели частоты и contextual diversity описаны в статье Cai & Brysbaert (2010). В оригинальном корпусе 33,5 млн слов, 46,8 млн иероглифов и 6 243 контекста. Контекстная распространённость полезна как дополнение к простой частоте: она отличает слово, часто повторяющееся в небольшом числе фильмов, от слова, встречающегося во многих фильмах.
