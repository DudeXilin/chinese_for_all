# SUBTLEX-CH — частотность китайских слов и иероглифов

SUBTLEX-CH — частотные списки китайского языка, построенные на корпусе субтитров фильмов и телесериалов. В исходной публикации описаны **33 546 516 слов**, **46 841 097 иероглифов** и **6 243 контекста** (фильма/видео).

## Источник и цитирование

- Cai, Q. & Brysbaert, M. (2010). *SUBTLEX-CH: Chinese Word and Character Frequencies Based on Film Subtitles*. PLOS ONE 5(6): e10729. https://doi.org/10.1371/journal.pone.0010729
- Официальный архив исходных таблиц: https://doi.org/10.1371/journal.pone.0010729.s002
- Дополнительная таблица с кодами частей речи PKU: https://doi.org/10.1371/journal.pone.0010729.s001
- Страница проекта авторов: https://www.ugent.be/pp/experimentele-psychologie/en/research/documents/subtlexch

При использовании данных цитируйте указанную публикацию. Страница проекта авторов указывает бесплатную загрузку для некоммерческого использования; перед распространением исходных данных в публичном репозитории проверьте действующие условия использования и атрибуции. В этом репозитории нет исходных субтитров — только частотные таблицы.

## Состав папки

| Файл | Содержание |
|---|---|
| `SUBTLEX-CH-WF.json` | Полная таблица частотности слов, JSON |
| `SUBTLEX-CH-CHR.json` | Полная таблица частотности иероглифов, JSON |
| `README.md` | Эта документация |

Оба JSON подготовлены автором пакетов `subtlex-ch-wf` и `subtlex-ch-chr` из исходных табличных данных. Структура сохраняет метаданные, исходные заголовки столбцов и строки таблицы. Это JSON-представление данных, а не исходный формат официального ZIP.

Официальный архив содержит также третью таблицу `SUBTLEX-CH-WF_PoS` с частотами слов, разделёнными по частям речи. В этой папке её **нет**. Она не требуется для обычного поиска общей частотности слова или иероглифа и не может быть достоверно восстановлена из двух имеющихся таблиц.

## Формат JSON и поиск записи

Оба файла имеют одинаковую общую структуру:

- `metadata` — метаданные корпуса;
- `headers` — исходные названия столбцов;
- `data` — массив записей.

Каждая запись в массиве `data` — объект с полями исходной таблицы. Китайские символы сохранены в UTF-8. Названия полей включают знаки пунктуации, поэтому к некоторым из них нужно обращаться через квадратные скобки, например `row["W/million"]`.

### Пример: получить частотность слова и иероглифа в Node.js

Пример подходит для серверного кода или отдельного скрипта Node.js. Пути указаны относительно корня репозитория:

```js
import { readFileSync } from "node:fs";

const words = JSON.parse(
  readFileSync("lib/SUBTLEX-CH/SUBTLEX-CH-WF.json", "utf8"),
);
const characters = JSON.parse(
  readFileSync("lib/SUBTLEX-CH/SUBTLEX-CH-CHR.json", "utf8"),
);

// Простой пример поиска. Для частых запросов ниже показан вариант с индексом.
const wordRow = words.data.find((row) => row.Word === "苹果");
const characterRow = characters.data.find((row) => row.Character === "人");

console.log(wordRow?.["W/million"], wordRow?.["W-CD%"]);
console.log(characterRow?.["CHR/million"], characterRow?.["CHR-CD%"]);
```

Метод `.find()` перебирает массив при каждом поиске. Если сайт будет запрашивать частотность многих карточек, лучше один раз построить индекс по ключу и затем получать запись напрямую:

```js
const wordIndex = new Map(words.data.map((row) => [row.Word, row]));
const characterIndex = new Map(
  characters.data.map((row) => [row.Character, row]),
);

const appleFrequency = wordIndex.get("苹果")?.["W/million"];
const personCharacterFrequency = characterIndex.get("人")?.["CHR/million"];
```

Индекс создаётся один раз на время жизни соответствующего процесса или страницы. После этого поиск по ключу не требует перебора всей таблицы.

**Важно для веб-приложения:** файлы в папке `lib/` не являются публичными статическими файлами. Не пытайтесь получать их браузерным `fetch("/lib/...")`: такой URL сам по себе не откроет файл из исходного кода. Если частотность нужна на сервере, читайте JSON серверным кодом. Если её нужно искать непосредственно в браузере, отдельно спроектируйте способ доставки данных — например, публичные файлы в `public/`, небольшой API или компактный индекс. Не импортируйте полные JSON в клиентский код автоматически: это может увеличить загружаемый JavaScript и расход памяти.

## Поля SUBTLEX-CH-WF — слова

Исходные заголовки: `Word`, `WCount`, `W/million`, `logW`, `W-CD`, `W-CD%`, `logW-CD`.

| Поле | Что означает | Как читать |
|---|---|---|
| `Word` | Китайская словарная единица/строка | Ключ для поиска записи. |
| `WCount` | Абсолютное число употреблений слова во всём корпусе | Сколько раз слово встретилось среди примерно 33,5 млн слов. |
| `W/million` | Частота на миллион слов | Нормализованный показатель. Например, значение 100 означает 100 зарегистрированных употреблений на миллион слов корпуса. |
| `logW` | Десятичный логарифм абсолютной частоты `WCount` | Логарифмически сжатый показатель, удобный для сравнения частотных и редких слов. Это не процент. |
| `W-CD` | Contextual diversity: число контекстов, где встретилось слово | Сколько из 6 243 фильмов/видео содержали слово хотя бы один раз. |
| `W-CD%` | Процент контекстов, где встретилось слово | Доля контекстов корпуса, в которых встретилось слово. |
| `logW-CD` | Десятичный логарифм `W-CD` | Логарифмическое представление числа контекстов. |

**Для рейтинга слов:** используйте `W/million` как основную меру частоты, а `W-CD%` — как дополнительную меру того, насколько широко слово распределено по разным фильмам. Слово может много раз повторяться в одном фильме и иметь высокий `WCount`, но сравнительно низкий `W-CD%`.

## Поля SUBTLEX-CH-CHR — иероглифы

Исходные заголовки: `Character`, `CHRCount`, `CHR/million`, `logCHR`, `CHR-CD`, `CHR-CD%`, `logCHR-CD`.

| Поле | Что означает | Как читать |
|---|---|---|
| `Character` | Один иероглиф/символ | Ключ для поиска. |
| `CHRCount` | Абсолютное число появлений символа | Считает символ везде, в том числе внутри слов; не означает, что символ использовался отдельно как слово. |
| `CHR/million` | Число появлений на миллион иероглифов | Нормализованная частота символа; знаменатель — символы, не слова. |
| `logCHR` | Десятичный логарифм `CHRCount` | Логарифмическая мера абсолютной частоты. |
| `CHR-CD` | Число контекстов, где встретился символ | Сколько из 6 243 фильмов/видео содержали иероглиф. |
| `CHR-CD%` | Процент контекстов, где встретился символ | Доля контекстов корпуса, в которых встретился иероглиф. |
| `logCHR-CD` | Десятичный логарифм `CHR-CD` | Логарифмическая мера распространённости по контекстам. |

**Не сравнивайте напрямую `W/million` и `CHR/million`:** первая величина рассчитана на миллион слов, вторая — на миллион иероглифов. Это разные знаменатели и разные единицы измерения.

## Части речи PKU

В официальной дополнительной таблице S1 описаны коды разметки частей речи PKU, используемые в таблице `SUBTLEX-CH-WF_PoS`. Например:

- `n` — существительное; `v` — глагол; `a` — прилагательное.
- `d` — наречие; `r` — местоимение; `m` — числительное.
- `p` — предлог; `c` — союз; `q` — классификатор.
- `nr` — имя человека; `ns` — географическое название; `nt` — название организации.
- `i` — идиома; `u` — служебная единица/частица; `w` — знак или пунктуация.

Это лишь примеры. Полный список кодов и определений приведён в официальной дополнительной таблице S1. Помните, что отдельная таблица `WF_PoS` в текущей папке не хранится.

## Пример расчёта

В опубликованных данных для слова `苹果` приводится `WCount = 766`, `W/million = 22.83`, `W-CD = 446`, `W-CD% = 7.14`. Это значит, что слово встретилось 766 раз в корпусе, примерно 22.83 раза на миллион слов и было обнаружено в 446 из 6 243 контекстов (около 7.14%). Перед использованием этого примера как автоматического теста проверьте, что значения совпадают с конкретной версией JSON в репозитории.

Для иероглифа `人` поле `CHR/million` показывает частоту символа на миллион иероглифов. Это не частота слова «человек» — для слова нужно смотреть отдельную запись в WF.

## Методологические ограничения

- Корпус отражает субтитры отобранных фильмов и видео, а не все современные разговоры или весь интернет.
- Частота в субтитрах не равна точной вероятности услышать слово в любом конкретном видео.
- `W-CD%` измеряет распространённость по документам корпуса, а не процент всех видео на китайском языке.
- Сегментация китайского текста на слова влияет на то, какие единицы учитываются в WF.
- Данные отражают корпус исследования 2010 года и не должны считаться актуальным рейтингом трендовых слов.
- Частотность не является напрямую уровнем HSK, оценкой сложности или рекомендацией по порядку изучения.
