# Russian–English–Chinese HSK dictionary

This folder contains `hsk.json`, a structured HSK vocabulary dataset with Chinese words, pinyin, HSK level, stroke/radical metadata, and English and Russian translations.

## Original project

The dataset was copied from [LiudmilaLV/json_hsk](https://github.com/LiudmilaLV/json_hsk).

The original author describes the data sources as:
- HSK vocabulary list: [gigacool/hanyu-shuiping-kaoshi](https://github.com/gigacool/hanyu-shuiping-kaoshi/)
- Stroke and radical information: [pwxcoo/chinese-xinhua](https://github.com/pwxcoo/chinese-xinhua/)
- Russian translations: [Chinese Plus](https://chineseplus.club/)

Please consult the original repositories and project for source-specific license and attribution requirements. The original `json_hsk` repository does not specify a license; the presence of an MIT license in an upstream source does not necessarily license all additional translations or contributions in this dataset.
